# Flower of Life - The Seven Movements

The Flower of Life animation tells the sacred geometry creation narrative through the **Seven Movements** - the first seven circles that form the Seed of Life, each drawn with intentional pacing and pauses to convey meaning.

## The Creation Story

Based on the cosmological narrative from sacred geometry traditions, creation unfolds through seven movements:

| Movement | Name       | Meaning                                                                              |
| -------- | ---------- | ------------------------------------------------------------------------------------ |
| 1        | **Monad**  | Spirit expands consciousness equally in all directions, creating infinite potential  |
| 2        | **Dyad**   | The Vesica Piscis forms - the "womb of creation" containing knowledge of proportion  |
| 3        | **Triad**  | The triangle emerges, representing balance through mind, body, and spirit            |
| 4        | **Tetrad** | The four elements (earth, water, air, fire) manifest physical matter                 |
| 5        | **Pentad** | Life begins, exemplified through the golden ratio governing biological growth        |
| 6        | **Hexad**  | Space and time crystallize - "six around one" forming molecules, crystals, and cells |
| 7        | **Heptad** | Return to Source through seven transformational steps, completing the Seed of Life   |

## Animation Timeline

The animation uses a balanced ~18 second cycle:

```
0.0s  - 1.5s   Monad draws (Spirit expands)
1.5s  - 2.3s   Pause
2.3s  - 3.3s   Dyad draws (Vesica Piscis forms)
3.3s  - 3.8s   Pause
3.8s  - 4.6s   Triad draws (Triangle emerges)
4.6s  - 4.9s   Pause
4.9s  - 5.5s   Tetrad draws (Matter manifests)
5.5s  - 5.7s   Pause
5.7s  - 6.3s   Pentad draws (Life begins)
6.3s  - 6.5s   Pause
6.5s  - 7.1s   Hexad draws (Crystallization)
7.1s  - 7.3s   Pause
7.3s  - 8.5s   Heptad draws (Return to Source)
8.5s  - 9.7s   Pause - Seed of Life complete
9.7s  - ~14s   Outer rings draw quickly
~14s - 16s    Final pause
16s           Cycle restarts
```

## Configuration

Timing can be adjusted in `src/config.ts`:

- `flowerV2StageDurations` - Draw time for each of the 7 circles
- `flowerV2StagePauses` - Contemplative pause after each stage
- `flowerV2OuterDrawDuration` - Speed for outer ring circles
- `flowerV2FinalPause` - Pause before the cycle restarts
